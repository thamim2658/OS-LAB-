Each experiment folder contains separate .c and .sh files for every
program/sub-part described in the lab manual.

Compiling C programs:
  gcc filename.c -o output
  ./output
(For threading programs use: gcc filename.c -o output -pthread)

Running Shell scripts:
  chmod +x filename.sh
  ./filename.sh
