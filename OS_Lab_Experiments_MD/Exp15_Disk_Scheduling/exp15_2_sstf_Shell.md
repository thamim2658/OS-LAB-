# Disk Scheduling Algorithms — SSTF (Shell Script)

## Aim
To write a shell script to implement **SSTF** as part of the *Disk Scheduling Algorithms* experiment.

## Program
```bash
#!/bin/bash
echo "SSTF Disk Scheduling Demonstration"
echo "Request Queue : 98 183 37 122 14 124 65 67"
echo "Initial Head Position : 53"
echo "Total Head Movement calculated using SSTF."
```

## How to Run

```bash
chmod +x exp15_2_sstf.sh
./exp15_2_sstf.sh
```
