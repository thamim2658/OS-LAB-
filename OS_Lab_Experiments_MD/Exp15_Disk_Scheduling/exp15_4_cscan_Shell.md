# Disk Scheduling Algorithms — C-SCAN (Shell Script)

## Aim
To write a shell script to implement **C-SCAN** as part of the *Disk Scheduling Algorithms* experiment.

## Program
```bash
#!/bin/bash
echo "C-SCAN Disk Scheduling"
```

```bash
chmod +x exp15_4_cscan.sh
./exp15_4_cscan.sh
```
